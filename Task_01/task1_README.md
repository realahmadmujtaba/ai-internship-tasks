# Task 1: Iris Dataset Exploration & Visualization

## Objective
This task involved performing comprehensive exploratory data analysis and visualization of the famous Iris dataset. The goal was to understand the relationships between different features and identify patterns among the three iris species (Setosa, Versicolor, and Virginica).

## Dataset
The Iris dataset contains 150 samples of iris flowers with four features measured from each sample: sepal length, sepal width, petal length, and petal width. Each sample is labeled with one of three species classes.

## Key Findings
The analysis revealed that petal length and petal width provide the clearest separation between species, with Setosa being distinctly different from the other two species. The visualizations showed strong correlations between certain features and confirmed that the dataset has no missing values, making it ideal for further analysis.
